# Justification des choix technologiques
* ### Gestion de base de données : fichier .json
* ### Animations : Anime.js et css animation
* ### Structure de Naviguation : multi-pager ( page principale puis 10 pages pour chaque projet )
* ### Hébergement : Github Pages 



# Idéées d'animation 
* Fondu d'apparition | les images / textes | apparaissent en douceur en glissant la page vers le haut ( Scroll )
* Effet de loupe | les images | zoom sur une image afin de l'afficher fluidement plus gros ( Zoom in ) 
* Survol interactif | textes / boutons | un changement subtile qui permet d'animer certains textes ou boutons en survolant avec la sourie ( On hover )
* Effet parallaxe | textes / boutons / images | différents éléments se déplacent lorsqu'on défile la page vers le bas
